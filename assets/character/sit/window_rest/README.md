# 창 위에서 쉬기

봉봉이가 실제 창 윗면에 앉아 가만히 쉬다가 일어나는 동작입니다. 바탕화면 바닥에서는 시작하지 않습니다.

- `sit_down_01`–`16`: IDLE에서 짧은 다리로 무릎을 굽힌 뒤 낮게 뛰어올라 털썩 앉습니다. 착석 순간 양옆으로 작은 먼지가 퍼졌다 사라집니다. 20fps입니다.
- `sit_rest_01`: 다리를 흔들지 않고 창 위에 가만히 앉아 쉬는 자세입니다.
- `sit_sleep_enter_01`–`08`: 기존 앉은 자세에서 눈을 감으며 잠듭니다. 12fps입니다.
- `sit_sleep_loop_01`–`11`: 눈을 감은 채 고개가 천천히 아래로 떨어졌다가 조금 빠르게 올라오는 반복 동작입니다. 웃는 입꼬리를 지우고 작은 일자 입으로 잠든 표정을 유지합니다. 1~8번 프레임은 각 180ms, 가장 아래인 9번은 100ms, 올라오는 10~11번은 각 110ms입니다.
- `sit_sleep_wake_01`–`16`: 입력이 돌아오면 현재 고개 각도에서 바로 이어서 고개를 들고 눈을 뜬 뒤 앉은 자세로 돌아옵니다. 18fps입니다. Zzz는 깨기 시작과 함께 사라집니다.
- `sit_up_01`–`63`: 양손으로 창을 짚고 양발을 한 번 올린 뒤 일어나 IDLE로 돌아갑니다. 40fps이며 마지막 프레임은 IDLE 첫 장과 동일합니다.
- `sit_window.aseprite`: 80프레임 최종 편집 원본이며 위 세 구간에 태그를 붙였습니다. `sit_window.gif`는 Godot의 높이 이동까지 반영한 전체 동작 미리보기입니다.
- `sit_sleep.aseprite`: 잠들기·꾸벅임·깨기의 35프레임 편집 원본입니다. `sit_sleep.gif`는 전체 흐름, `sit_sleep_loop.gif`는 꾸벅임 반복 미리보기입니다. 두 GIF에 `Z`, `Zz`, `Zzz`가 차례로 나타납니다. Godot에서는 캐릭터가 왼쪽을 볼 때도 글자가 뒤집히지 않도록 글자를 별도로 그립니다.

192×192 투명 프레임입니다. IDLE과 짧은 다리의 앉은 자세를 시작·끝 그림으로 Grok 영상을 새로 생성하고, sprite-gen 2.6.0으로 배경을 제거했습니다. 다리가 길게 보이는 중간 프레임은 제외하고 점프 높이를 약 9픽셀로 줄였습니다. Aseprite에서 착석 먼지를 창 높이에 맞춰 정리하고, 앉은 자세의 무릎 아래 정강이를 3픽셀 줄였습니다. 일어서는 초반에도 그 비율이 자연스럽게 이어지도록 보정을 점차 줄입니다. 생성 영상과 작업 중간물은 `.godot/`에 보관합니다.

자동 이동 중 창 위에서 멈췄을 때 일정 확률로 앉아 4–7초 쉬고 일어납니다. 현재 Windows 세션에 키보드·마우스 입력이 20초 이상 없으면 창 위에서 멈춘 순간 확실히 앉고, 앉기 동작 다음에 바로 잠듭니다. 입력이 없는 동안 꾸벅임과 `Zzz`가 반복됩니다. 입력이 돌아오면 기다리지 않고 현재 고개 각도에서 바로 눈을 뜨고 일어납니다. 입력 시간 정보를 받지 못하면 기존의 보통 앉기 동작만 사용합니다. 창이 이동하면 함께 움직이고, 창이 사라지면 FALL로 이어집니다. 클릭·드래그·방향키는 곧바로 해당 동작으로 전환하며, Space를 누르면 일어난 뒤 자동 이동을 멈춥니다.
