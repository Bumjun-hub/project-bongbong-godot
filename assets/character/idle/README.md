# Bongbong Idle Animation Set

확정된 `../source/bongbong_sd17_base.png`를 기준으로 Aseprite 1.3.18.5에서 제작한 전신 픽셀 프레임이다. 기준 원본, 기존 참고 프로젝트, Godot 씬/스크립트/설정은 수정하지 않았다.

## 파일

각 폴더 `default/`, `pockets/`, `arms_crossed/`에 다음을 저장했다.

- `idle_<name>.aseprite`: 편집 가능한 192×192 RGB+alpha 원본, 6프레임, 상태 이름 태그, 프레임별 시간 포함. 한 레이어에 완성된 전신 프레임이 들어 있다.
- `idle_<name>_01.png` ~ `_06.png`: 투명 192×192 PNG.
- `idle_<name>.png`: 1152×192 가로 6칸 시트. 자르기/패딩 없이 각 셀은 192×192.
- `idle_<name>.gif`: 재생 확인용. GIF의 제한된 팔레트는 게임용 RGBA PNG를 대체하지 않는다.
- 상위 `manifest.json`: 좌표, 프레임 시간, 캔버스, 기준점, 루프 정보.

`production/`은 제작 Lua와 검수 자료다. `.gdignore`로 Godot 에셋 탐색에서 제외했다. 스크립트는 오프라인 픽셀 제작 도구이며 게임 런타임 코드가 아니다.

## 프레임 시간

| 상태 | 1~6번 시간(ms) | 루프 | 평균 FPS |
|---|---|---|---|
| IDLE_DEFAULT | 600, 400, 500, 450, 450, 600 | 3.0초 | 2.00 |
| IDLE_POCKETS | 750, 500, 450, 650, 550, 700 | 3.6초 | 1.67 |
| IDLE_ARMS_CROSSED | 650, 450, 500, 600, 450, 650 | 3.3초 | 1.82 |

프레임 시간은 일정하지 않다. 평균 FPS로 일괄 재생하면 원래의 호흡 리듬과 달라진다. 향후 SpriteFrames를 만들 때 manifest의 개별 시간을 반영한다.

6프레임은 기본 → 어깨/가슴 상승 → 머리까지 연동한 정점 → 정점 유지 → 어깨/가슴 단계 → 기본 복귀다. 픽셀 단계는 3개이며 3·4, 2·5, 1·6은 각각 같은 그림이다. 미세한 1px 동작에 불필요한 중간 자세를 생성하지 않고 타이밍으로 들숨/날숨을 표현한다.

## 자세별 호흡

- DEFAULT: 기준 Base의 편한 자세. 어깨와 가슴이 1px 상승하고, 정점에서 머리와 내려놓은 팔이 1px 따라 움직인다.
- POCKETS: 팔꿈치를 몸 가까이에 내리고 양손을 주머니 입구 안으로 가렸다. 손/주머니 접점은 고정하고 윗가슴·어깨와 머리가 반응한다. 호흡 주기는 가장 느리다.
- ARMS_CROSSED: 가슴 높이에서 짧은 전완을 편안하게 겹쳤다. 한 손은 반대쪽 팔 아래에 가리고, 다른 손은 일부만 보이게 했다. 앞으로 접힌 팔에 맞춰 소매도 수정했다. 팔짱과 가슴의 그림은 함께 1px 이동하여 팔짱 모양이 바뀌지 않는다.

두 특수 자세는 `production/pose_revision/`의 생성 참고 그림에서 팔/소매/주머니 부분을 Aseprite로 정렬·편집했다. 수정 전후 비교와 프롬프트는 해당 폴더의 README에 있다. DEFAULT 파일 9개는 SHA-256 비교로 변경 없음을 확인했다.

Sprite 전체 위치 이동, 전체 확대/축소, 회전, 관절 보간, 런타임 중간 프레임 생성은 사용하지 않았다. 필요한 영역의 픽셀을 정수 좌표로 옮기고 접합 행을 보완하여 완성 프레임에 저장했다. 얼굴/안경/머리는 동일한 픽셀 그림을 유지한다.

## 정렬과 검증

- 캔버스 192×192, 중심 기준 x=95, 지면 하단 경계 y=174.
- 모든 프레임에서 y=153 이하 하체/발 영역은 기준 Base와 픽셀 단위로 동일하다.
- 각 루프의 1·6번 프레임은 완전히 같다. 최대 머리 이동은 위로 1px이며 크기 변화는 없다.
- PNG, 시트 각 셀, 저장된 Aseprite의 프레임 픽셀을 다시 읽어 대조: 일치.
- Aseprite/GIF의 6프레임 및 루프 총 시간: 일치.
- 검수 결과: `production/validation.json`, `production/export_validation.json`.
- PNG 원본과 확대 시트를 정적으로 시각 검수했다. 실제 Windows 데스크톱 펫 실행 검증은 수행하지 않았다.

## 직접 확인

각 GIF를 열거나 Aseprite 원본을 열어 타임라인 재생 버튼으로 3~4회 반복해서 본다. 원본 1배와 Nearest 2~4배에서 모두 확인한다.

1. 발바닥이 흔들리지 않고 머리의 1px 변화가 호흡으로 읽히는지.
2. 주머니 입구와 손 연결이 자연스러운지.
3. 팔짱의 두 팔이 작은 크기에서도 구분되는지.
4. 호흡 속도와 강도가 장시간 보기 편안한지.

별도 blink와 세 자세 사이의 전환 프레임은 아직 만들지 않았다. 이번 루프는 각 자세 내부의 반복을 위한 것이며, 자세를 즉시 교체하면 팔 위치가 바뀐다. Godot 랜덤 Idle 로직은 미구현이다.
