# 창 꼭대기에서 내려가기

슬라이딩 중 벽에 붙어 있는 올라간 신발의 접촉점에서 회청색 먼지 뭉치가 발 위로 퍼지고 약 0.32초 만에 사라집니다. 먼지 크기는 4–8px이며 피부와 구분되는 색을 사용합니다. 뒤쪽의 떠 있는 발에서는 나오지 않습니다. 움직인 거리마다 소량 발생하며, 멈추면 새 먼지가 나오지 않습니다. Godot의 `descent_controller.gd`가 그리는 효과이므로 스프라이트 원본에 먼지를 붙이지 않습니다.

Sprite-gen 2.6.0과 Grok 영상 생성으로 만든 새 동작입니다. 기존 올라가기 영상을 역재생하지 않았습니다.

- `lower_001.png`부터 `lower_097.png`: 바깥을 보고 서기 → 창을 향해 몸 돌리기 → 양손으로 꼭대기 짚기 → 다리 한쪽씩 내리기 → 매달리기. 24fps, Godot 재생 배율 1.15.
- 현재 내려가기: 첫 프레임은 마지막 `lower_097.png`를 그대로 쓰고, 이후 `slide_hair_002.png`부터 `slide_hair_048.png`를 24fps로 반복합니다. 머리 중심·앞머리·얼굴·안경·몸·손·다리는 유지하고, 정수리와 뒤쪽의 느슨한 머리끝 세 곳만 상승 기류에 0–2.5px 들렸다 돌아옵니다. 처음 약 0.33초 동안 가속하고 이후 140px/s로 내려갑니다. 손·다리를 번갈아 움직이지 않습니다.
- `slide_hair.aseprite`, `slide_hair.gif`: 현재 슬라이딩의 편집 원본과 미리보기입니다.
- `lower.aseprite`, `slide_hair.aseprite`: 현재 사용 중인 동작의 최종 편집 원본입니다.
- `lower.gif`: 시작 동작 미리보기입니다. GIF는 투명 경계가 반투명 PNG보다 거칠 수 있습니다.
- `manifest.json`: 첫 동작의 프레임별 모서리 기준 위치입니다. 첫 자세는 IDLE, 마지막 자세는 기존 벽타기 자세의 픽셀을 그대로 사용합니다.
- `slide_hair_manifest.json`: 현재 머리끝 반복 동작의 프레임 정보와 끊김 검사 결과입니다.

이전 발 교대 후보와 제작 중간 프레임·영상·중복 미리보기는 정리했습니다. 현재 사용하는 PNG와 최종 Aseprite 편집 원본은 보관합니다.

모든 런타임 PNG는 192×192이며 배경은 투명합니다. 현재 슬라이딩의 첫 프레임은 마지막 내려오기 자세를 그대로 사용해 전환 순간 그림이 바뀌지 않습니다. Grok 영상에서 관찰한 두 번의 바람 패턴을 참고해 Aseprite MCP로 원래 머리끝만 움직였습니다. 생성 영상의 머리 전체 변형은 사용하지 않습니다. 머리 중심·얼굴·몸은 원본 픽셀을 유지합니다. 반복 끊김 검사 seam ratio는 0.1604로 기준 2.0 이하를 통과했습니다. 가려진 구간에서는 멈추고, 다시 내려갈 수 있으면 가속하며 출발합니다. 창 아래에서 떨어질 때 슬라이딩 속도를 낙하로 전달합니다.

창 위에서 자동 이동하다 끝에 도달하면 내려갑니다. 창 위의 봉봉이에게 키 입력이 전달되는 상태에서는 `D`로 가까운 모서리에서 내려가도록 요청할 수 있습니다. `Space`나 드래그로 중단할 수 있습니다. 공중에서 창이 사라지거나 실제 창의 아래 끝에 도달하면 기존 FALL → LAND로 이어집니다.
