# IDLE 디테일을 기준으로 걷기/뛰기 정리

기준: assets/character/idle/soft_three_quarter_right/default/idle_01.png
입력: 직전 skin_matched_motions (걷기 24, 가벼운 뛰기 18, 통통 뛰기 28프레임).
출력: assets/character/detail_matched_motions.

## 실제 수정

- 걷기는 이전 원본과 원래 IDLE의 머리 위치를 비교하여 프레임마다 이동량을 구하고, 현재 부드러운 IDLE의 머리·얼굴 디테일을 그 위치에 맞춰 적용했다.
- 가벼운 뛰기는 머리의 위치/크기/기울기를 추정한 좌표 변환으로 IDLE 디테일을 적용했다. 프레임 사이 추정값의 작은 흔들림을 완화하되 원본 머리의 높이 변화는 유지한다.
- 통통 뛰기는 웃는 표정과 들어 올린 손을 보존하고 머리카락 부분만 IDLE 명암/가닥 디테일을 참조했다. 피부 및 그 주변 2픽셀은 머리 디테일 덮어쓰기에서 보호했다.
- 옷은 같은 소재의 이웃 픽셀 6개 이상에 둘러싸인 색 이상점만 주변 중앙값으로 정리했다. 걷기 415, 가벼운 뛰기 507, 통통 뛰기 1640픽셀(각 동작 모든 프레임 합계).
- 추가 외곽선 침식이나 전체 블러는 적용하지 않았다. 모든 출력 알파는 입력과 정확히 동일하여 기존 실루엣과 투명 배경을 유지한다.
- 전체 프레임을 새로 생성한 작업은 아니다. 기존 모션 위에 IDLE 참조 디테일을 맞춰 적용하고 소재 내부 이상점을 정리한 작업이다. 포즈별 주름과 원래 그림의 세부 형태 차이는 남아 있다.

## 검증

70개 PNG의 알파/실루엣 동일, 머리 및 옷 편집 마스크 밖의 모든 RGBA 동일. 세 동작 모두 추적된 머리 위치가 실제로 변해 고정되지 않음을 확인했다. 대표 전후 이미지 및 전체 연락시트에서 확인했다. Godot Main이 새 70개 텍스처를 실제로 읽으며 프레임 수/순서/지속시간/FPS가 기존과 같은지 검증 통과.

원본 및 직전 결과는 보존. Godot의 walk/run_light/run_bouncy 이미지 참조만 변경했다. IDLE/DRAG/FALL 및 포켓·팔짱 옷색 리소스는 유지했다.

재현: analyze.py -> stabilize.py -> protect_hands.py -> Aseprite MCP로 apply.lua -> verify_pixels.py -> preview.py. publish.py는 최초 연결 변경 기록이며 *_before.txt가 직전 상태 백업이다.
