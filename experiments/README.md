# 스프라이트 제작 기록

생성 프롬프트, 파이프라인 보고서, 편집 스크립트와 검증 코드를 보관한다.
영상 및 중간 프레임은 용량이 커서 이 폴더의 Git 제외 규칙을 따른다. 2026-09-24와 2026-09-27에 사용하지 않는 로컬 중간물을 정리했다.
제작 스크립트와 보고서는 남겨 두었지만, 중간물을 읽는 스크립트를 다시 실행하려면 해당 생성 단계를 다시 수행해야 한다.

Godot 실행에 필요한 최종 PNG와 Aseprite 원본은 `assets/character/`에 포함되어 있다.
현재 가벼운 달리기는 `sprite-gen-run/grok-light-jog-02/`에서 제작했으며,
제작 당시 검증 스크립트 중 이전 에셋 경로를 사용하는 것은 재생성이나 경로 변경이 필요하다. 현재 프로그램의 동작 검사는 루트 `tests/`의 스크립트를 사용한다.

2026-09-27 정리에서는 중간 PNG·GIF·영상·로그, 교체된 옛 모션, 임시 검증용 복사본과 사용하지 않는 가져오기 캐시를 삭제했다. 현재 사용하는 최종 프레임·GIF·Aseprite는 보관한다. 추가 생성 기록은 Git에서 제외한 로컬 작업 폴더에 둔다.

현재 적용 내용과 조작 방법은 루트의 `IDLE_TEST.md`, `WALK_TEST.md`,
`RUN_TEST.md`, `DESKTOP_WINDOW_TEST.md`를 참고한다.
